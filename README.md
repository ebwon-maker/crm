# 후원자 관리 (GitHub Pages 배포용)

## 이 리포지토리에는 후원자 데이터가 없습니다
`index.html`, `app.js`에는 실제 후원자 정보가 전혀 포함되어 있지 않습니다.
사용자가 브라우저에서 엑셀 파일을 직접 업로드해야 데이터가 채워지며,
그 데이터는 **서버로 전송되지 않고 해당 브라우저에만** 저장됩니다.

## 배포 방법
1. 이 두 파일(`index.html`, `app.js`)만 GitHub 리포지토리에 커밋
2. Settings → Pages → 배포 소스 지정
3. 발급된 URL로 접속

## 반드시 확인할 것 — 리포지토리 공개 범위
- GitHub Pages는 리포지토리를 Private으로 설정해도 **사이트 자체는 기본적으로 전체 공개**입니다.
  (비공개 Pages는 GitHub Enterprise Cloud 조직 전용 기능이며, 개인/Pro/Team 플랜에는 없습니다)
- 이 코드 자체는 데이터를 담고 있지 않아 커밋해도 안전하지만,
  **누구나 URL만 알면 빈 업로드 화면까지는 접근 가능**합니다.
- 그 사람이 실제 엑셀 파일을 가지고 있지 않는 한 후원자 정보를 볼 수는 없지만,
  URL 자체를 비공개로 유지하고 싶다면 Cloudflare Access 등 별도 인증 계층을 앞단에 추가하는 것을 권장합니다.

## 데이터 흐름 (기기 간 이동 방법)
1. 엑셀 파일 업로드 → 브라우저 메모리에서 파싱
2. 추가/수정/삭제 → 이 브라우저의 localStorage에 자동 저장 (기기 종속, 다른 기기와 동기화 안 됨)
3. 작업 후 "내보내기(.xlsx)" 클릭 → 최신 상태를 파일로 다운로드
4. 다른 기기·다음 세션에서는 그 파일을 다시 업로드해서 이어서 작업

## 하지 말아야 할 것
- 업로드했던 원본 엑셀 파일이나 내보내기(.xlsx) 결과물을 이 리포지토리에 커밋하지 마세요.
  (`.gitignore`에 `*.xlsx`, `*.xls`, `*.csv` 추가 권장)
- 공용 PC/공유 브라우저에서 사용 후에는 브라우저 설정에서 이 사이트의 저장 데이터(localStorage)를 삭제하세요.
